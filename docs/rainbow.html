Welcome to Rainbow!

Arrange the tiles so that each column contains a single color, but you can only move a pile of tiles from one column to another if the bottom tile in the pile has the same color as the tile at the top of the column the pile is being moved to.

A move consists of three characters representing the source column, row of the bottom of the pile and destination column. For example, the move b5a moves the pile in column b starting at row 5 to column a if that move is legal.
